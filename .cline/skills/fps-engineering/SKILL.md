# FPS Engineering

Read current code and tests first. Reproduce bugs or add the smallest regression test. Make the smallest safe change. Run targeted tests, regression/smoke gates, and the real WAMP gate for WordPress/WooCommerce changes. Review git diff/status. Do not bypass gates or perform broad refactors during targeted fixes.
