قیمت‌گذاری خودکار و حرفه‌ای محصولات ووکامرس بر اساس نرخ زنده طلا و ارز – مناسب فروشگاه‌های طلا، سکه و ارز در ایران.

== Description ==

**طلا ارز پرو (Formula Price Sync)** یک افزونه تخصصی ووکامرس است که قیمت محصولات را بر اساس نرخ لحظه‌ای طلا، سکه و ارز به‌صورت خودکار محاسبه و به‌روزرسانی می‌کند.

این افزونه برای فروشگاه‌های طلا و جواهر، فروشندگان سکه و کسب‌وکارهایی که قیمت‌شان وابسته به نوسان بازار است طراحی شده و از فرمول استاندارد صنف طلا در ایران پشتیبانی کامل دارد.

### ویژگی‌های نسخه ۲.۰.۰

* **فرمول استاندارد طلا** مطابق قانون صنف (مالیات فقط روی اجرت + سود، نه روی ارزش خام طلا)
* **پشتیبانی کامل از محصولات ساده و متغیر** (هر ورییشن تنظیم مستقل دارد)
* **دریافت نرخ از چند منبع با Failover خودکار** (TGJU → Navasan → Nobitex → Manual)
* **Circuit Breaker** برای جلوگیری از تغییرات ناگهانی قیمت (آستانه پیش‌فرض ۲۵٪)
* **همگام‌سازی دسته‌ای** با Action Scheduler (چانک‌های ۵۰تایی و بدون قفل شدن سایت)
* **قفل قیمت محصول** – محصولات خاص از به‌روزرسانی خودکار مستثنی می‌شوند
* **نمایش همزمان ریال و تومان** در داشبورد، متاباکس و لیست محصولات
* **ستون قیمت محاسباتی** در لیست محصولات ووکامرس (قابل غیرفعال‌سازی)
* **فیلتر دسته‌بندی و برچسب** در همگام‌سازی دسته‌ای
* **کرون مستقل سمت سرور** – وابسته به بازدید کاربر نیست
* **اعلان تلگرام و پیامک** هنگام فعال شدن فیوز، قطع API یا اتمام سینک دسته‌ای
* **خروجی CSV از تاریخچه تغییرات قیمت**
* **صفحه وضعیت سلامت سیستم** – لایسنس، آخرین سینک، Circuit Breaker، کرون، Providerها و خطاها در یک نگاه
* **Logger مرکزی** با سطوح دیباگ / اطلاعات / هشدار / خطا
* **فارسی‌سازی اعداد و تبدیل قیمت به حروف**
* **رابط کاربری مدرن** با پشتیبانی Dark Mode
* **پاک‌سازی خودکار کش** (WP Rocket، LiteSpeed، W3 Total Cache و ...)
* **لایسنس با اعتبارسنجی سرویس فروشنده از طریق Adapter/Integration خارجی**

== Installation ==

1. فایل ZIP را از طریق پیشخوان وردپرس (افزونه‌ها → افزودن → بارگذاری افزونه) نصب کنید.
2. افزونه را فعال کنید.
3. به منوی **طلا ارز پرو** بروید و کلید لایسنس را وارد کنید.
4. در تنظیمات، منبع نرخ و واحد نمایش (ریال/تومان) را مشخص کنید.
5. در صفحه ویرایش هر محصول، گزینه «فعال‌سازی قیمت‌گذاری خودکار» را روشن و فرمول را تنظیم کنید.
6. (اختیاری اما توصیه‌شده) کرون مستقل را طبق راهنمای داخل تنظیمات یا فایل راهنما پیکربندی کنید.


== License and marketplace configuration ==

بسته نهایی برای خریدار شامل ابزار توسعه یا دستور ساخت مجدد نیست. همان ZIP رسمی منتشرشده را نصب و فعال کنید.

توکن محصول و تنظیمات اعتبارسنجی لایسنس هرگز داخل سورس/ZIP hard-code نمی‌شوند و باید روی سرور خریدار تعریف شوند.

برای ژاکت:
  define( 'FPS_LICENSE_PROVIDER', 'zhaket' );
  define( 'FPS_ZHAKET_PRODUCT_TOKEN', 'YOUR_PRODUCT_TOKEN_HERE' );

برای راست‌چین:
  define( 'FPS_LICENSE_PROVIDER', 'rastchin' );
  define( 'FPS_RASTCHIN_PRODUCT_TOKEN', 'YOUR_PRODUCT_TOKEN_HERE' );
  define( 'FPS_RASTCHIN_ACTIVATE_URL', 'https://YOUR-LICENSE-SERVICE/activate' );
  define( 'FPS_RASTCHIN_VALIDATE_URL', 'https://YOUR-LICENSE-SERVICE/validate' );

نکات امنیتی:
* مقدار token هرگز در ZIP، لاگ یا رابط کاربری نمایش داده نمی‌شود.
* صفحه سلامت سیستم فقط وضعیت پیکربندی را نمایش می‌دهد.
* نبودن پیکربندی معتبر، license gate را fail-closed نگه می‌دارد و mutation کسب‌وکار انجام نمی‌شود.
* خریدار نباید فرایند توسعه یا ساخت مجدد بسته را روی سایت مقصد اجرا کند.

== Frequently Asked Questions ==

= آیا مالیات روی ارزش خام طلا محاسبه می‌شود؟ =
خیر. مطابق قانون صنف طلا، مالیات فقط روی مجموع (اجرت + سود) اعمال می‌شود.

= آیا از محصولات متغیر پشتیبانی می‌شود؟ =
بله. هر ورییشن می‌تواند وزن، اجرت، سود و تنظیمات مستقل داشته باشد.

= اگر یک محصول نباید با نوسان بازار تغییر کند چه کار کنم؟ =
در متاباکس محصول گزینه «قفل قیمت (عدم به‌روزرسانی خودکار)» را فعال کنید.

= چرا بعضی محصولات در همگام‌سازی دیده نمی‌شوند؟ =
محصولاتی که قفل قیمت دارند یا گزینه فعال‌سازی فرمول روی آن‌ها خاموش است، از صف همگام‌سازی حذف می‌شوند.

= کرون وردپرس (WP-Cron) کافی است؟ =
برای دقت بیشتر، استفاده از کرون مستقل سمت سرور (cPanel / DirectAdmin) توصیه می‌شود تا به‌روزرسانی وابسته به بازدید کاربران نباشد.

= چگونه از تاریخچه قیمت خروجی بگیرم؟ =
از صفحه تاریخچه در منوی افزونه می‌توانید با فیلتر تاریخ و نوع تغییر، خروجی CSV دریافت کنید.
